# Strategic Roadmap: AgencyOS

This roadmap outlines the evolution of AgencyOS from a core management tool to an AI-driven SaaS platform. We prioritize items based on the **RICE Framework** to ensure maximum impact on agency operations.

## 🚀 Now (Q2 2026)
*Focus: Stabilization & Multi-Tenancy*
- [ ] **SaaS Foundation**: Implementing Multi-tenancy at the database level for strict isolation.
- [ ] **Advanced RBAC**: Deploying Owner/Manager/Contributor roles to align with agency hierarchies.
- [ ] **Automated Invoicing (v1)**: Basic invoice generation from completed tasks to reduce manual billing time.
- [ ] **Capacity View**: Initial resource management dashboard for project managers.

## 📈 Next (Q3 2026)
*Focus: Strategic Optimization*
- [ ] **RICE Scoring Engine**: Integrating data-driven prioritization directly into task management.
- [ ] **Client Stakeholder Portal**: Read-only access for clients to monitor real-time project health.
- [ ] **Tiered Billing Integration**: Payment gateway setup (Stripe/LemonSqueezy) with feature-gating logic.
- [ ] **Enhanced Reporting**: Detailed profitability analysis at the client and project levels.

## 🔮 Later (Q4 2026 & Beyond)
*Focus: Intelligence & Ecosystem*
- [ ] **Predictive AI Analytics**: Cash flow forecasting and project timeline estimation using Llama-3/Groq.
- [ ] **Public API**: Enabling third-party integrations (CRM, Slack, Zapier).
- [ ] **Mobile App**: Dedicated experience for task execution and field updates.
- [ ] **AI Project Assistant**: Automated task breakdown and assignment suggestions based on historical performance.

---
*Note: This roadmap is a living document and subjects to change based on market trends and specific agency feedback.*
